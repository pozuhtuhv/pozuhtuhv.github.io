### 0. 돌아온 기록
쉬는 기간이 길었습니다, 그동안 많은 생각을 하게 됐어요.<br>
미뤄왔던 글을 다시 써봅니다.<br>
생략된 게 많아요. 사진을 별로 안 남겨놨거든요.<br>

### 1. 동물친구들
{% include image-path.html cols=2 start=1 end=2 %}
거의 한 달에 한 번씩 가는 미용실의 강아지 친구들입니다.<br>
세상 느긋한 친구들이에요.<br>
책 보면서 쓰다듬어주다 보면 자고 있을 때가 많아요.<br>
보기만 해도 힐링되는 귀여운 친구들입니다.<br>
{% include image-path.html cols=2 start=3 end=4 %}
왼쪽 사진은 30% 확률로 출근길에 한 번씩 얼굴을 비춰주는 고양이입니다.<br>
귀여운 친구인데, 가까이서는 볼 수 없는 친구예요.<br>
오른쪽 사진은 추석 때 산소에 갔다가 만난 고양이인데, 밑에 있는 과수원에서 돌아다니고 있어서 찍은 사진입니다..<br>
멀리서라도 지켜볼 수 있어서 고맙네요.<br>

### 2. 집반찬 만들기
{% include image-path.html cols=2 start=5 end=6 %}
어묵볶음과 두부조림입니다.<br>
전자레인지로 쉽게 만들 수 있어서 자주 해먹는 반찬이에요.<br>
정말 밥도둑이 따로 없어서 너무 좋네요.<br>
{% include image-path.html cols=1 start=7 end=7 %}
순살 닭다리입니다.<br>
사실 첫 도전이라 굽기만 해봤는데, 조금 느끼한 감이 없지 않아 있었습니다.<br>
한 번에 양을 너무 많이 한 탓도 있지만, 껍질의 바삭함은 최고였네요.<br>
자주 해먹을 것 같아요, 가성비가 좋거든요.<br>

### 3. 당근하기
{% include image-path.html cols=1 start=8 end=8 %}
당근으로 책장 구하기입니다.<br>
집안 물건들을 이케아로 채우려고 당근에 지박령처럼 상주하고 있어요.<br>
좋은 매물이 떠서 바로 채팅하고 받으러 가봤습니다.<br>
{% include image-path.html cols=2 start=9 end=10 %}
사실.. 크기가 이 정도일 줄은 몰랐어요..<br>
크기는 그렇다 쳐도 무게가 상당해서, 집에 들고 올라오는 데 꽤 애를 먹었습니다.<br>
집이 또 2층이라 혼자서 꾸역꾸역 들고 올라왔고, 결국 집에 들여놓은 모습이에요.<br>
다음 날이 쉬는 날이라 다행이지, 아니었으면 일하기 힘들 뻔했네요.<br>

### 4. 이북리더기
{% include image-path.html cols=2 start=11 end=12 %}
첫 기기를 구경하고 있는 모습입니다.<br>
크기도 적당하고, 쉬는 날에 특별한 일정이 없으면 이북리더기로 시간을 많이 보낸답니다.<br>
{% include image-path.html cols=1 start=13 end=13 %}
다른 책들은 이 사진에 없는데, 해리포터 소설은 3권까지 쭉 읽어놨습니다.<br>
사실 해리포터가 조금 지루해진 느낌이 있어서, 지금은 교양책으로 넘어왔어요.<br>
사진에 보이는 것처럼 설득의 심리학은 틈틈이 읽고 있어요.<br>

### 5. 진주 친구찾아가기
{% include image-path.html cols=3 start=14 end=16 %}
진주에 친구들이 살아서, 한번 놀러 간 날입니다.<br>
딱히 찍어놓은 사진은 없고요,<br>
진주역 도착해서 한 컷, 저녁에 고기 먹다가 한 컷, 친구 집에 플스5가 있어서 아세토코르사를 잠깐 맛본 사진밖에 없네요.<br>

### 6. 목걸이
{% include image-path.html cols=1 start=17 end=17 %}
이번에 구매한 것들 중에 제일 마음에 드는 액세서리입니다.<br>
살면서 목걸이라는 걸 해본 적이 없는데,<br>
팔찌를 좋아해서 팔찌만 차고 다녔거든요. 그런데 일을 하다 보니 팔찌가 계속 신경 쓰이더라고요.<br>
그래서 목걸이에 관심을 가져봤어요.<br>
눈에 띄는 장식보다는 무난하고 미니멀한 목걸이를 찾다가 하나 장만하게 됐습니다.<br>
왼쪽은 순은 1mm이고, 오른쪽은 써지컬 저가형 목걸이입니다.<br>
아무래도 순은 제품에 손이 더 가서 지금은 순은 목걸이만 쓰고 있어요.<br>
1mm는 쓰다 보니 너무 불안할 것 같아서 1.5mm도 순은으로 하나 더 장만했고, 지금은 1.5mm를 거의 문신템처럼 쓰고 있어요.<br>

### 7. 문화생활하기
{% include image-path.html cols=3 start=18 end=20 %}
쉬는 날에 볼 영화가 뭐가 있을까 고민하다가 고른 영화입니다.<br>
인생에서 가장 기억에 남는 영화가 뭐냐고 물어보면, 저는 어바웃타임이라고 말해요.<br>
후반부에 나오는 "하루를 두 번 사는 것처럼 살기"가 특히 오래 남았어요.<br> 
첫 번째는 평소처럼, 두 번째는 놓쳤던 것들을 알아차리면서요.<br>
시간여행 능력을 거창한 곳이 아니라 사랑하는 사람과 평범한 하루를 더 잘 보내는 데 쓰는 영화라,<br>
이만큼 기억에 남는 영화가 없어요.<br>
{% include image-path.html cols=1 start=21 end=21 %}
두 번째 영화는 친한 분께 추천받아서 본 '오직 그대만'입니다.<br>
사실 옛날 영화에는 손이 잘 안 갔는데, 여운이 정말 오래 남는 영화였어요.<br>
다른 사랑 영화와는 또 다른 느낌으로 순애가 잘 담겨 있어서,<br>
마음이 따뜻해지는 영화였습니다.<br>

### 8. 마니또
{% include image-path.html cols=1 start=22 end=22 %}
이번에 한 달 동안 같이 지낸 게임 친구들이 정모를 한다고 해서 계획된 이벤트입니다.<br>
게임 시간이 잘 안 맞아서 친해질 기회가 없었던 분들인데,<br>
평탄한 삶에 한 번쯤은 이런 이벤트가 필요한 것 같아서 참석하기로 했어요.<br>
(선물이 고민이에요 고민,,,)<br>
사실 제가 나이가 제일 많아요... 기대도 되고 걱정도 되는 이벤트입니다.<br>
12월 초에 서울 구경을 한번 할 것 같은데, 그때는 다른 분들도 만나볼 수 있으면 좋겠네요.<br>
